# SAYDIAN Health U19 交接说明（2026-09-30）

## 先看结论

这是国际版 `SAYDIAN Health` 的 U19 工作分支交接，不是生产发布许可。Android 已有 U19 发现、连接、通知订阅、当天数据读取及受控重连的真机证据；间歇性 GATT 服务发现超时仍未证明根治。U19 每日汇总只有在国际服务明确声明 `data.dailySummaryVersions=true` 后才上传。服务端相应契约在独立分支，尚无可核验的真实非零数据“手表→本机→隔离服务→重新读取”闭环。

本次交付包括固定 Git 提交的 App/服务端源码快照及 Android 内部 QA APK。原始 EB1 协议文档、账号/密钥、原始健康日志、手机截图和生产备份不在包内；从包中恢复源码后仍须先更新远端。

## 源码与接口地图

| 位置 | 接手重点 |
| --- | --- |
| `lib/services/urion_eb1_protocol.dart`、`test/urion_eb1_protocol_test.dart` | 16 字节 EB1 帧、校验、历史/时间解析；协议示例中有错误校验值，不以示例替代测试。 |
| `lib/services/urion_wearable_bridge.dart` | U19 会话、能力、健康读取、手动测量、设置；数据歧义项继续保守处理。 |
| `android/app/src/main/kotlin/cc/saidian/saydian_app/UrionGattTransport.kt`、`ios/Runner/UrionGattTransport.swift` | 原生 GATT，服务发现和通知订阅完成前不得显示连接成功；Android 一次性重建恢复分支还缺故障现场验证。 |
| `lib/services/local_health_store.dart`、`lib/services/sync_service.dart` | 不可变日汇总版本、按环境/账号隔离和待同步状态；重复读取不累加步数。 |
| `lib/services/global_health_api.dart`、`test/global_api_test.dart` | 国际 V2 能力门禁；404、缺字段、`false` 不上传日汇总。 |
| 服务端 `apps/api`、Prisma 迁移、`docs/implementation-log/2026-09-29-health-daily-summary-contract.md` | 国际会员鉴权、每日版本保存和折叠读取；先在独立库验收迁移。 |

第一方请求只允许 `https://app.saydian.cn/global`。App 的关键读路由是 `GET /global/api/saydian-app/v2/health/capabilities`；必须在已登录会员响应中明确看到 `data.dailySummaryVersions=true` 才发送 `aggregation:{kind:"daily_summary",localDate:"YYYY-MM-DD"}`。`observedAt` 是读取时刻，不冒充数据所属日期。旧客户端、关爱、统计和 AI 报告必须按服务端版本折叠契约处理；没有服务端确认 `acceptedIds` 不标记上传成功。
