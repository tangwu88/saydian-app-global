## 代码与接口地图

| 位置 | 职责和注意点 |
| --- | --- |
| `lib/services/urion_eb1_protocol.dart`、`test/urion_eb1_protocol_test.dart` | EB1 16 字节帧、校验、分包及时间/数据解码；不得以文档示例中的错误校验值覆盖测试向量。 |
| `lib/services/urion_wearable_bridge.dart` | U19 会话、能力、健康历史、测量和设置；未知/有歧义的数据不上传。 |
| `android/app/src/main/kotlin/cc/saidian/saydian_app/UrionGattTransport.kt`、`ios/Runner/UrionGattTransport.swift` | 原生 GATT 通道；必须等服务发现与通知订阅完成才宣布连接。Android 的一次性新 GATT 恢复分支尚未在故障现场触发验证。 |
| `lib/services/local_health_store.dart`、`lib/services/sync_service.dart` | 按账号保留本地不可变日汇总版本及待同步状态；重试不得改记录 ID/内容。 |
| `lib/services/global_health_api.dart`、`test/global_api_test.dart` | 国际 V2 能力查询、日汇总提交；404/缺字段/false 一律关闭日汇总上传。 |
| 服务端 `apps/api`、Prisma 迁移和 `docs/implementation-log/2026-09-29-health-daily-summary-contract.md` | 独立分支实现能力声明、版本保存和折叠读取；数据库迁移仅在隔离库先验收。 |

第一方请求固定在 `https://app.saydian.cn/global`。App 请求 `GET /global/api/saydian-app/v2/health/capabilities`，只有会员鉴权后的标准 V2 响应严格为 `data.dailySummaryVersions=true` 才上传 `aggregation:{kind:"daily_summary",localDate:"YYYY-MM-DD"}`。服务端须按“用户＋设备＋指标＋所属日期”折叠版本，旧客户端不应看到重复累计。`observedAt` 是读取时间，不得当作手表数据所属日期。
