## 每次修改前

- [ ] 核对仓库、分支、origin、HEAD、差异及干净状态；fetch 后保留其他分支，不盲目合入 main。
- [ ] 阅读当前交接、最新审查、修复记录和剩余验收项；用文件/函数追踪实际入口，不用相似旧页替代。
- [ ] 写明本次改动的原因、受影响平台、账号、设备/固件、指标、数据阶段和回滚方式。
- [ ] 保护现有手机数据库、待上传数据和会话；不以卸载、清库、删 pending 作为排障首选。

## 账号、页面与存储

- [ ] 登录、refresh、退出、注销、旧 401 和新登录做乱序组合；持久化比较写入与比较清除均绑定会话代次。
- [ ] A→B、同账号重登、未登录→登录分别检查健康、关爱、消息、商城、地址、积分、收藏、物流与草稿。
- [ ] 已经加载的数据与在途回包分别清理；页面返回栈也检查，不能只验证 API 包装函数。
- [ ] SQLCipher owner/environment 隔离、不可读库/sidecar 保留、恢复与覆盖安装校验有独立证据。
- [ ] 旧域名缓存仅在已认证身份映射成功后迁移；失败保留原件，美国不能回落国内。
